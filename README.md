# GOLD-PRICES-ANALYSIS
Gold is more than a financial asset; it holds significant economic and cultural value worldwide and is commonly purchased for marriages, gifts, savings, and investment. 

However, constantly changing gold prices make it difficult for individuals, families, and businesses to determine the right time to purchase or manage gold. Since prices are influenced by multiple market factors, our project explores how deep learning can be used to predict gold prices and support more informed decisions in both personal and global financial contexts.
